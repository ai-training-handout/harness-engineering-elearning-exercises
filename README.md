# ハーネスエンジニアリング研修 — 演習の配布物

ハーネスエンジニアリング研修（e-learning）の演習で、受講者の手元に置くファイル一式。
動画・スライドと、ここに含まれない素材（答え合わせ・隠しテスト・完成形リポジトリ）は、研修の受講ページ（LMS）にある。

第4部2章「コード生成ハーネス」と第4部3章「レビュー＆検証ハーネス」の2つの演習は1本のストーリーでつながっている：**第4部2章で仕様書からアプリを0から生成し、第4部3章ではそのアプリへの機能追加 PR をレビューする**。

## 利用条件

- この配布物は、本研修の受講者が学習に使うためのものである。ライセンスは付与していない（オープンソースではない）。
- 受講者本人の学習に使える。演習で作った成果物や、雛形の書き方を自分の業務のリポジトリに取り入れることも構わない。
- 第三者への再配布・転載・販売、ほかの研修や講座の教材としての利用はできない。
- 質問は受講ページ（LMS）の案内に従う。このリポジトリでは Issue・Pull Request を受け付けていない。

## 使い方

第2部3章〜第3部4章の素材は、読む・写す・自分のプロジェクトへコピーするだけでよい（このフォルダをリポジトリにする必要はない）。以下は第4部2章・3章の使い方。

1. このリポジトリを取得する（`git clone` か、GitHub の Code → Download ZIP）。
2. 章のフォルダを**取得した場所の外へコピーし**、コピー先を**演習用のリポジトリのルート**にする。取得した場所の中で始めると、演習のコミットやブランチ（Step 8〜10 で使う）がこの配布物のリポジトリに混ざる。Claude Code はコピー先のフォルダで起動する。

   ```sh
   cp -r harness-engineering-elearning-exercises/第4部2章-コード生成 ~/harness-codegen
   cd ~/harness-codegen
   git init && git add -A && git commit -m "配布物"
   ```

   第4部3章も同じ（例: `~/harness-review`）。最初のコミットがあると、Step 10 で戻る地点がはっきりする。
3. 最初に一度 `claude` を対話モードで起動し、「このフォルダを信頼するか」の確認で信頼を選ぶ（章ごとにフォルダが違うので、それぞれで1回）。信頼を選んでいないフォルダでは、ヘッドレス実行（`claude -p`）が `.claude/settings.json` の allow を読まず、許可した操作でも止まる。
4. `00_演習手順書.md` を Step 0 から順に進める。各 Step の**完了条件を自分で確かめてから**次へ進む。
5. 時間は目安。超えても構わない。詰まったら手順書の「つまずき所」を読む。それでも進めないときは、受講ページの完成形リポジトリで次の Step から合流する（下の「この配布物に含まれていないもの」）。

## この配布物に含まれていないもの（受講ページからダウンロードする）

答え合わせ・隠しテスト・完成形は、先に見ると演習の意味がなくなるので、この公開の配布物には入れていない。必要な場面で、受講ページの各章からダウンロードする。

| 素材 | 使う場面 | 受講ページのファイル |
|---|---|---|
| 答えの例（第2部3章 #077） | 自分で書き出したあと | 第2部3章 `第2部3章_答えの例-消せる1行.pdf` |
| 記入例（第3部1章 #092） | 自分の表を埋めたあと | 第3部1章 `第3部1章_記入例-制御点マッピング.pdf` |
| 完成形リポジトリ（第4部2章） | 詰まったとき。`step-N-done` タグから次の Step に合流する | 第4部2章 `第4部2章_完成形リポジトリ.zip` |
| 隠しテスト・穴あり実装・E2E の倍率の参考値 | 第4部2章 Step 10 | 第4部2章 `第4部2章_Step10_隠しテストと穴あり実装.zip` |
| 完成形リポジトリ（第4部3章） | 詰まったとき。`step-N-done` タグから次の Step に合流する | 第4部3章 `第4部3章_完成形リポジトリ.zip` |
| 答え合わせ（仕込まれた欠陥）と Step 7 の参考値 | 第4部3章 Step 5 で自分の言葉で書いたあと | 第4部3章 `第4部3章_答え合わせ.pdf` |

隠しテストは、エージェントに見せないことで意味を持つ。ダウンロードしたあとも、エージェントの作業フォルダでは読ませない（第4部2章 Step 2 の deny）。

## 前提環境

- Claude Code（バージョンを控えておく。演習の挙動はバージョンで変わることがある）
- Python 3.11 以上と `uv`
- Node.js 20 以上・22 LTS 推奨（第4部2章の Playwright MCP。手順書 Step 0 で `claude mcp list` の接続確認まで済ませる。ブラウザが見つからないと言われたら `npx -y playwright install chromium`）
- Git
