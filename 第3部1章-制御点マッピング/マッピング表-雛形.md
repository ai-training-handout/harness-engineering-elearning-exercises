# 第3部1章 演習　制御点マッピング表（雛形）

スライド #092「【演習】自プロジェクトの .claude/ を点検する」で使う記入用紙。
自分のプロジェクトの `.claude/` と CLAUDE.md を開き、今ある設定を**8つの制御点**に対応づける。

- 行は8つの制御点（#088 の分類）。Settings は8つを収める器なので、行にはしない。
- 「どこを見れば分かるか」は点検のヒント。上から順に開いて確かめる。
- 「使っているか」は ✓（使っている）／△（置いてあるが効いていない・中身が空・個人設定だけ）／－（無い）のどれかで書く。
- 迷ったら「メモ」に書いて先へ進む。全部を埋めることより、未着手を1つ選ぶことを優先する。

## 1. マッピング表

| 効く場面 | 制御点 | どこを見れば分かるか | どこに書いてあるか（ファイル・キー） | 使っているか | メモ |
|---|---|---|---|---|---|
| 常時 | CLAUDE.md | リポジトリ直下とサブディレクトリの `CLAUDE.md`・`~/.claude/CLAUDE.md`。何行あるか（`wc -l CLAUDE.md`） | | | |
| 常時 | Output Styles | `.claude/settings.json` の `outputStyle` キー・`.claude/output-styles/` | | | |
| 呼び出し時 | Skills | `.claude/skills/<名前>/SKILL.md`・`~/.claude/skills/` | | | |
| 呼び出し時 | カスタムコマンド | `.claude/commands/*.md`・`~/.claude/commands/` | | | |
| 呼び出し時 | MCP | `.mcp.json`・`claude mcp list` の出力 | | | |
| イベント発火時 | Hooks | `.claude/settings.json`（と `settings.local.json`）の `hooks` キー・`.claude/hooks/` のスクリプト | | | |
| イベント発火時 | Permissions | `.claude/settings.json` の `permissions` キー（`allow`・`deny`・`ask`）。`/permissions` でも確かめられる | | | |
| コンテキスト分離 | サブエージェント | `.claude/agents/*.md`・`~/.claude/agents/` | | | |

> 個人設定（`~/.claude/`）とプロジェクト設定（`.claude/`）のどちらに書いてあるかも「どこに書いてあるか」欄に残す。チームで共有されるのはプロジェクト側だけ。
